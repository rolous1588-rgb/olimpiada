# Olimpiadas FICAM 2026

Sitio de inscripción (`index.html`) y administración (`admin.html`) de las Olimpiadas FICAM 2026.
Los datos se guardan en Supabase (tablas `of_*`). Las claves de `js/config.js` son públicas por diseño;
la seguridad está en las políticas de la base de datos. No subir aquí claves secretas.
